# Publication policy

This repository is a public educational derivative. It must never contain:

- original recruitment-test PDFs or exact question text;
- supplied or downloaded household microdata;
- candidate submission PDFs, archives, or source packages;
- personal names from the private assessment workspace;
- files produced by masking, sampling, perturbing, or resampling restricted records.

All teaching rows are generated independently by `scripts/generate_teaching_data.py`. Fictional countries and training districts are used to prevent readers from treating simulated values as real estimates.

Official DHS-style unit-record datasets require registered access for an approved research use. This repository teaches analytical patterns without redistributing those datasets. See [The DHS Program data resources](https://dhsprogram.com/data/visualizations/).

The automated publication guard is a backstop, not a substitute for human review. Before every release, inspect the full tracked-file list and the built website.
