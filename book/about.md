# About this learning lab

This independent learning lab teaches analytical decisions that recur in coding assessments and applied research: safe joins, missing-data rules, reproducible cleaning, fixed-effect design, robust inference, visual checks, and honest interpretation.

The examples use fictional countries and training districts. They should never be interpreted as evidence about real populations.

## Technical stack

- Jupyter Book 2 for the reading site
- JupyterLite and Pyodide for browser Python
- Google Colab links for hosted notebooks
- GitHub Pages for static hosting
- Plain JavaScript for local quizzes and certificates
