# Glossary

**Assertion:** A statement that stops execution when a required condition is false.

**Cardinality:** The expected key relationship in a join, such as one-to-one or many-to-one.

**Coordinate reference system:** The rule that gives geographic coordinates their meaning.

**Denominator:** The count below a rate or proportion.

**Fixed effect:** Indicator controls for average differences across named categories.

**HC1 standard error:** A heteroskedasticity-consistent covariance estimate with a finite-sample adjustment.

**Identifier:** A value used to distinguish records. It is often text even when it contains only digits.

**Missing value:** Information that is unavailable or undefined. Missing is not the same as zero.

**Repeated cross-section:** Separate samples observed in different survey waves. It is not a panel unless the same units are followed.

**Synthetic data:** Artificial observations generated from a documented process, not copied or perturbed from private records.
