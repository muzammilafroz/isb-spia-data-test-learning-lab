# Applied Data Coding Learning Lab

This course teaches a complete research workflow: inspect files, validate keys, construct variables, make maps, fit regressions, test assumptions, and explain limitations in plain English.

The data are fictional and generated for teaching. Nothing on this site is an official institutional assessment, answer key, or credential.

## Choose how to work

:::{card} Read and run
Each lesson is rendered as a readable chapter. Use **Run in browser** to open the same notebook in JupyterLite without installing Python.
:::

:::{card} Use Colab
Each notebook also has an **Open in Colab** link for a full hosted Python environment.
:::

:::{card} Test yourself
After each lesson, complete the test notebook and paste its answer bundle into the browser test. Passing requires 80 percent.
:::

Tests, progress, entered names, and certificates remain in your browser. This site has no analytics, account system, or submission backend.
