# Course map

The orientation takes about 10 minutes. Each substantive module takes 60 to 90 minutes, including its test.

| Module | You will learn to | Practice |
|---|---|---|
| 1. Python and pandas | Read tables, select rows, work with missing values, write checks, and validate joins | 8 questions |
| 2. Geospatial analysis | Choose keys, build geometry, classify values, retain repeated coordinates, and inspect a saved map | 8 questions |
| 3. Household rates | Construct denominators, normalize IDs, merge, append, clean special codes, and preserve provenance | 10 questions |
| 4. Econometrics | Read formulas, diagnose rank, use wave effects, report HC1 uncertainty, and avoid causal overclaiming | 8 questions |
| 5. Research defense | Reproduce outputs, verify artifacts, troubleshoot failures, disclose AI use, and defend decisions | 8 questions |
| Capstone | Combine the whole workflow | 12 questions |

Pass all six assessments at 80 percent to unlock a local self-assessed completion record.

## Suggested route

For each module, read the rendered lesson, run its short cells, open the blank test notebook, and paste the final JSON bundle into the local browser form. If a first attempt does not pass, use the feedback to identify the weak concept, return to that lesson section, and try again.
